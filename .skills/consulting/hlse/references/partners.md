# Partner Tooling Reference

## Microsoft

Microsoft's partner programme (Microsoft AI Cloud Partner Program) provides MSPs with access to a broad portfolio of cloud and on-premises products. Licensing is transacted through the Cloud Solution Provider (CSP) programme, enabling direct or indirect resale with margin and billing control.

**Products available for MSP resale:**

- **Microsoft 365** — Productivity and collaboration suite including Exchange Online, Teams, SharePoint, OneDrive, and Microsoft 365 Apps. Available across Business (Basic, Standard, Premium) and Enterprise (E1, E3, E5) SKUs, plus Frontline Worker tiers.
- **Microsoft Azure** — Full public cloud platform covering compute, storage, networking, databases, AI/ML services, and platform services. Billed through CSP with consumption-based pricing.
- **Microsoft Intune** — Cloud-based endpoint management for mobile devices and PCs, including policy enforcement, app deployment, and compliance reporting.
- **Microsoft Defender for Business / Endpoint / Identity / Office 365 / Cloud** — Layered security products spanning endpoint protection, identity threat detection, email security, and CSPM/CWPP capabilities.
- **Microsoft Entra ID** (formerly Azure Active Directory) — Identity and access management including SSO, MFA, Conditional Access, Privileged Identity Management, and B2B/B2C federation.
- **Microsoft Purview** — Compliance and data governance platform covering data classification, DLP, information protection, eDiscovery, audit, and insider risk management.
- **Microsoft Sentinel** — Cloud-native SIEM/SOAR platform for security operations, log ingestion, threat detection, and automated response.
- **Microsoft Copilot for Microsoft 365** — AI assistant integrated across M365 apps, enabling natural language interaction with documents, email, Teams, and business data.
- **Windows 365 / Azure Virtual Desktop** — Cloud PC and virtual desktop solutions for remote and hybrid workforce scenarios.
- **Microsoft Teams Calling / Teams Phone** — Cloud telephony and PSTN calling add-ons for Teams, including Calling Plans and Operator Connect.
- **Microsoft Power Platform** — Low-code development tools including Power BI (analytics), Power Apps (custom apps), Power Automate (workflow), and Power Pages (web portals).

## AWS

AWS's MSP Partner Programme provides tiered access to Amazon Web Services infrastructure and managed services. Partners can transact through the AWS Marketplace or via the AWS Partner Network (APN), with private pricing, co-sell opportunities, and programmatic incentives available at higher tiers.

**Products available for MSP resale:**

- **Amazon EC2** — Scalable virtual compute instances across a broad range of instance families (general purpose, compute-optimised, memory-optimised, GPU).
- **Amazon S3** — Object storage service with tiered storage classes, lifecycle policies, and replication capabilities.
- **Amazon RDS / Aurora** — Managed relational database services supporting MySQL, PostgreSQL, SQL Server, Oracle, and MariaDB. Aurora provides a high-performance, serverless-capable variant.
- **AWS IAM / IAM Identity Center** — Identity and access management for AWS resources, including SSO federation and centralised permission management across accounts.
- **AWS CloudTrail / CloudWatch** — Audit logging and operational monitoring services providing visibility into API activity, resource health, and performance metrics.
- **AWS Backup** — Centralised backup service across AWS resources including EC2, RDS, EFS, and DynamoDB.
- **AWS Control Tower / AWS Organizations** — Multi-account governance and landing zone automation for managing customer environments at scale.
- **Amazon Connect** — Cloud-based contact centre platform with omnichannel support, AI-powered routing, and analytics.
- **AWS Direct Connect** — Dedicated private network connectivity between on-premises environments and AWS regions.
- **AWS Managed Services (AMS)** — AWS-operated managed services overlay providing operational management, patching, monitoring, and change management on behalf of partners and customers.

## Google

Google Cloud's partner programme (Google Cloud Partner Advantage) enables MSPs to resell Google Cloud Platform (GCP) and Google Workspace products. Partners transact through the Google Cloud Marketplace or via reseller agreements, with access to co-sell support, deal registration, and managed reseller pricing.

**Products available for MSP resale:**

- **Google Workspace** — Cloud-native productivity and collaboration suite including Gmail, Calendar, Drive, Docs, Sheets, Slides, Meet, and Chat. Available across Business Starter, Standard, Plus, and Enterprise tiers.
- **Google Cloud Compute Engine** — Infrastructure-as-a-service offering virtual machines across standard, high-memory, high-CPU, and GPU instance types.
- **Google Kubernetes Engine (GKE)** — Managed Kubernetes service for container orchestration, with Autopilot and Standard operating modes.
- **Google Cloud Storage** — Scalable object storage with multi-regional, regional, nearline, and coldline storage classes.
- **Cloud SQL / AlloyDB / Spanner / Firestore** — Managed database services spanning relational (Cloud SQL, AlloyDB), globally distributed (Spanner), and NoSQL (Firestore) options.
- **Chronicle SIEM / Chronicle SOAR** — Google's cloud-native security operations platform providing petabyte-scale log ingestion, threat detection, and automated response capabilities.
- **Google Security Command Center** — Centralised security and risk management platform for GCP workloads, covering vulnerability detection, misconfiguration alerts, and compliance reporting.
- **Gemini for Google Workspace** — AI assistant capabilities integrated across Workspace apps (Docs, Gmail, Meet, Sheets), enabling generative AI features for end users.
- **Google Cloud AI / Vertex AI** — Managed platform for building, deploying, and scaling machine learning models, including access to foundation models and the Gemini model family via API.
- **Google Cloud Interconnect / Cloud VPN** — Dedicated and encrypted private connectivity options between on-premises environments and Google Cloud regions.

## AvePoint

AvePoint is a Microsoft-focused SaaS company providing data management, governance, and migration solutions built on top of Microsoft 365. Its Fly partner programme enables MSPs to resell and deliver AvePoint products under a managed service model, with multi-tenant management capabilities and white-label options available at higher partner tiers.

**Products available for MSP resale:**

- **AvePoint Cloud Backup** — Multi-workload backup and recovery for Microsoft 365, covering Exchange Online, SharePoint Online, OneDrive, Teams, and Microsoft 365 Groups. Provides granular restore, geo-redundant storage options, and automated backup scheduling.
- **AvePoint Opus** (formerly Cloud Management) — Lifecycle management and governance platform for Microsoft 365, including automated policies for inactive sites, overshared content, guest access expiry, and storage quota management.
- **AvePoint Fly SaaS** — Migration platform supporting tenant-to-tenant, on-premises SharePoint, file share, Google Workspace, and Dropbox migrations to Microsoft 365. Supports pre-migration analysis, scheduling, and delta sync.
- **AvePoint Cloud Governance** — Structured provisioning and governance engine for Microsoft 365 workspaces (Teams, SharePoint, Groups), enforcing naming conventions, metadata, approval workflows, and access review cycles.
- **AvePoint Policies and Insights (PI)** — Security posture assessment and configuration management tool providing visibility into M365 tenant settings, sharing policies, and deviations from security baselines.
- **AvePoint Workspace Management** — Ongoing operational management of Microsoft 365 workspaces (Teams, SharePoint sites, Microsoft 365 Groups) across their full lifecycle, including automated renewals, archival, access reviews, and ownership enforcement. Designed for MSPs managing workspace sprawl at scale across multiple customer tenants.
- **AvePoint Baseline Management** — Continuous monitoring and enforcement of M365 tenant configuration baselines, alerting on configuration drift against approved security and compliance benchmarks. Enables MSPs to maintain a known-good configuration state across customer environments and demonstrate compliance posture over time.

## Wiz

Wiz is an agentless cloud security platform delivered as SaaS, providing deep visibility into cloud environments across AWS, Azure, GCP, OCI, and Kubernetes. Wiz's MSSP programme enables managed security service providers to deliver Wiz capabilities to customers under a managed model, with multi-tenant management, API access, and programmatic reporting.

**Products available for MSP resale:**

- **Wiz CSPM (Cloud Security Posture Management)** — Continuous assessment of cloud resource configurations against security benchmarks (CIS, NIST, SOC 2, ISO 27001, PCI-DSS, etc.), with automated risk prioritisation and remediation guidance.
- **Wiz CWPP (Cloud Workload Protection Platform)** — Agentless vulnerability scanning of virtual machines, containers, and serverless functions, including OS package vulnerabilities, exposed secrets, and malware detection.
- **Wiz CIEM (Cloud Infrastructure Entitlement Management)** — Visibility into IAM permissions across cloud environments, identifying excessive privileges, unused entitlements, and toxic combinations that create privilege escalation paths.
- **Wiz DSPM (Data Security Posture Management)** — Discovery and classification of sensitive data (PII, credentials, intellectual property) stored in cloud datastores, with exposure risk context layered on top.
- **Wiz Defend** (formerly Wiz Runtime / CDR) — Real-time threat detection and response for cloud runtime environments, including container escape, lateral movement, and cryptomining detection.
- **Wiz Code** — Shift-left security scanning integrated into CI/CD pipelines and source control (GitHub, GitLab, ADO), providing IaC misconfiguration detection and secrets scanning pre-deployment.
- **Wiz Sensor** — Optional lightweight eBPF-based agent for runtime behavioural monitoring in environments where agentless coverage is insufficient.
- **Wiz Security Graph** — Underlying graph-based risk correlation engine connecting findings across identity, network, workload, and data to surface attack paths and prioritise critical exposure.

## Zscaler

Zscaler is a cloud-native Zero Trust security platform delivered entirely as a service, requiring no on-premises security appliances. Zscaler's partner programme (ZIA/ZPA resale and MSSP tracks) enables MSPs to deliver Zscaler as a managed service, with multi-tenant management through the Zscaler for Partners portal and API-driven automation.

**Products available for MSP resale:**

- **Zscaler Internet Access (ZIA)** — Cloud-delivered Secure Web Gateway (SWG) providing URL filtering, SSL inspection, DNS security, CASB, DLP, advanced threat protection, and firewall-as-a-service for users connecting to the internet, regardless of location.
- **Zscaler Private Access (ZPA)** — Zero trust network access (ZTNA) solution replacing traditional VPN, providing identity-aware, least-privilege access to internal applications without exposing the network.
- **Zscaler Digital Experience (ZDX)** — End-to-end digital experience monitoring providing visibility into application performance, network path quality, and device health from the user perspective, used for proactive troubleshooting.
- **Zscaler Deception** — Deception technology integrated within the Zscaler platform to detect lateral movement and active threats using decoy assets and lures.
- **Zscaler Posture Control / CNAPP** — Cloud-native application protection platform extending Zscaler's zero trust principles into cloud workload and infrastructure security, including CSPM, CIEM, and container security capabilities.
- **Zscaler Data Loss Prevention (DLP)** — Inline and out-of-band DLP enforced across web, email, cloud app, and endpoint channels, with pre-built dictionaries for PII, PCI, and PHI data types.
- **Zscaler Cloud Firewall** — Next-generation firewall capabilities delivered via Zscaler's cloud, providing application-layer inspection and policy enforcement for all user traffic without physical appliances.
- **Zscaler Workload Communications** — Zero trust connectivity for cloud workloads (VMs, containers, serverless) communicating with other workloads or the internet, without exposing workload IPs.
