# Partner Programme Quick Reference

Summary of partner programmes relevant to The Instillery's sales and delivery activities. Use alongside the partner-engagement skill for deal-specific guidance.

---

## Microsoft

**Programme:** Microsoft AI Cloud Partner Program (MCPP)
**The Instillery's status:** Azure Cloud Solution Provider (CSP) — Direct or Indirect tier (confirm current tier)

### Key Programme Components

| Component | What It Provides | When to Use |
|-----------|----------------|------------|
| CSP Transact | Licence Microsoft products (Azure, M365, Intune, Defender, etc.) with partner margin and billing control | All Microsoft licensing for customers |
| Solution Partner Designations | Recognition across 6 solution areas (e.g. Infrastructure, Security, Modern Work) — unlocks co-sell eligibility | Demonstrate specialisation in proposals |
| Azure IP Co-sell | Microsoft field team co-sells eligible partner IP alongside Azure consumption | Large Azure engagements where Microsoft field can help accelerate |
| MACC Eligibility | Eligible partner solution costs count against a customer's Azure Committed Spend | Customers with Azure monetary commitments |
| Deal Registration | Register qualified opportunities for pricing protection and incentive payouts | Any significant Microsoft opportunity |
| MDF (Market Development Funds) | Co-funded marketing activities aligned to a Microsoft solution area | Demand generation, events, content |
| Partner-Funded PoC | Funding for proof-of-concept engagements (via FastTrack or partner programmes) | Complex deals requiring a PoC to de-risk |

### Microsoft Portals

| Portal | Purpose |
|--------|---------|
| Partner Center (partner.microsoft.com) | Deal registration, solution designations, CSP management, MDF |
| Azure Cost Management | Customer Azure consumption and CSP billing |
| Microsoft 365 Admin Center | M365 tenant management for CSP customers |

### Microsoft Solution Areas (for positioning)

| Solution Area | Relevant Products |
|--------------|-----------------|
| Infrastructure | Azure compute, storage, networking, hybrid |
| Data & AI | Azure AI, Fabric, Synapse, Power BI |
| Digital & App Innovation | Azure DevOps, GitHub, App Service, Functions |
| Business Applications | Dynamics 365, Power Platform |
| Modern Work | Microsoft 365, Teams, Copilot |
| Security | Defender suite, Sentinel, Entra ID, Purview, Intune |

## AWS

**Programme:** AWS Partner Network (APN)
**Track:** Resell / MSP

| Component | What It Provides | When to Use |
|-----------|----------------|------------|
| APN Partner Portal | Deal registration, co-sell requests, training, incentives | All AWS opportunities |
| ACE (AWS Customer Engagements) | Register deals and request AWS field support (co-sell) | Opportunities >$50k ACV |
| AWS Marketplace | Transact solutions; customer can use AWS Committed Spend | Customers with AWS committed spend |
| Partner-Funded PoC | AWS funding for qualifying proof-of-concept workloads | De-risk complex migration or modernisation deals |
| Competency Programmes | Industry or technology specialisations that unlock funding and visibility | Demonstrate depth in a specific domain |

### AWS Partner Portal
- URL: partnercentral.aws.amazon.com
- Deal registration (ACE): Required for co-sell incentives
